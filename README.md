# VKinder — Бот-знакомств для ВКонтакте

Бот для ВКонтакте, который помогает пользователям находить потенциальных партнёров по заданным параметрам (возраст, город, пол). Кандидаты отбираются через VK API, а пользователи могут добавлять анкеты в «Избранное» или «Чёрный список», а также просматривать сохранённые профили.

---

## 📦 Установка

### Требования

- Python 3.12+
- PostgreSQL
- Аккаунт ВКонтакте с:
  - токеном пользователя (user token)
  - заполненными полями: дата рождения (ДД.ММ.ГГГГ), пол, город

### Шаги

```powershell
# 1. Клонируйте репозиторий
git clone <repo-url>
cd VKinder

# 2. Создайте виртуальное окружение
python -m venv .venv
.venv\Scripts\Activate.ps1

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Создайте файл .env в корне проекта
# Пример содержимого .env:
#   VK_TOKEN=ваш_user_token_из_vk
#   TOKEN=ваш_group_token
#   GROUP_ID=id_вашей_группы
#   PASSWORD=пароль_от_postgres

# 5. Создайте базу данных
#   CREATE DATABASE db_vkinder;

# 6. Запустите бота
python basic_code.py
```

## 🗂 Структура проекта

```
VKinder/
├── basic_code.py     # Точка входа. Longpoll-цикл, маршрутизация команд, инициализация БД и VKClient.

├── vkclient.py       # Обёртка над VK API: получение данных пользователя, поиск кандидатов, фото.
├── requirements.txt  # Зависимости Python.
├── .gitignore        # Игнорируемые файлы Git.
└── db_scheme.png     # Схема базы данных.
```

## 🔗 Взаимосвязи между файлами

```
basic_code.py
    │
    ├──→ db.py          (insert_vk_user, insert_candidates, insert_photos,
    │                    show_next_candidate, add_to_favorite, add_to_black_list,
    │                    show_favorite_list)
    │
    ├──→ models.py     (SQLAlchemy-модели: VKUser, Candidates, Photo, Favorites, BlackList)
    │
    └──→ vkclient.py   (VKClient: get_user_info, search_candidates, get_3_candidate_photo)

db.py
    ├──→ models.py     (импортирует все модели)
    └──→ vkclient.py  (передаёт client в функции БД для вызова VK API)

vkclient.py
    └──→ vk-api       (вызовы: users.get, users.search, photos.get)
```

## 📋 Команды бота

| Команда | Описание |
|---------|----------|
| `поиск` | Заполняет профиль, ищет кандидатов, показывает первую анкету |
| `далее` | Показывает следующего кандидата |
| `в избранное` | Добавляет текущего кандидата в избранное |
| `в чс` | Добавляет текущего кандидата в чёрный список |
| `избранное` | Выводит список сохранённых кандидатов с фото |
| `помощь` | Отображает список команд |
| `пока` | Прощается с пользователем |

## 🧩 Основные функции

### `basic_code.py`

| Функция | Назначение |
|---------|------------|
| `write_msg()` | Отправка сообщения через VK API (с клавиатурой и вложениями) |
| `handle_search()` | Запуск поиска: профиль → кандидаты → фото → первый показ |
| `handle_next()` | Показ следующего кандидата |
| `handle_favorite()` | Добавление в избранное |
| `handle_blacklist()` | Добавление в чёрный список |
| `handle_show_favorite()` | Вывод списка избранных с фото |
| `route_message()` | Маршрутизация команд к обработчикам |

### `db.py`

| Функция | Назначение |
|---------|------------|
| `make_engine()` | Создание SQLAlchemy-движка |
| `make_session()` | Создание фабрики сессий |
| `create_tables()` | Создание всех таблиц в БД |
| `insert_vk_user()` | Создание/обновление профиля пользователя |
| `insert_candidates()` | Поиск и сохранение кандидатов из VK |
| `insert_photos()` | Сохранение до 3 фото для каждого кандидата |
| `show_next_candidate()` | Выбор следующего кандидата (исключая ЧС), отправка с клавиатурой |
| `add_to_favorite()` | Добавление в таблицу `favorites` |
| `add_to_black_list()` | Добавление в таблицу `black_list` |
| `show_favorite_list()` | Загрузка избранных кандидатов с фото |

### `vkclient.py`

| Функция | Назначение |
|---------|------------|
| `get_user_info()` | Получение данных пользователя: город, пол, возраст |
| `build_search_params()` | Формирование параметров для `users.search` |
| `search_candidates()` | Поиск кандидатов по параметрам |
| `get_3_candidate_photo()` | Получение 3 самых популярных фото |
| `bdate_to_age()` | Конвертация даты рождения в возраст |
| `build_profile_url()` | Формирование ссылки `vk.com/...` |

## 🗃 Схема базы данных

```
┌──────────────────┐       ┌───────────────────────────┐       ┌──────────────────┐
│     vk_user      │       │        candidates         │       │      photo       │
├──────────────────┤       ├───────────────────────────┤       ├──────────────────┤
│ id        (PK)   │───┐   │ id         (PK)           │   ┌───│ id       (PK)    │
│ age              │   └──▶│ vk_id      (NOT NULL)     │   │   │ candidate_id(FK) │
│ sex              │       │ owner_id   (FK→vk_user)   │   │   │ attachment       │
│ city_id          │       │ name       (NOT NULL)     │   │   └──────────────────┘
│ last_shown_id    │       │ surname    (NOT NULL)     │   │
└──────────────────┘       │ link       (NOT NULL)     │   │
         │                 │                           │   │
         │                 │ ┌───────────────────────┐ │   │
         └─────────────────▶│   favorites           │◀┘   │
         │                  ├───────────────────────┤     │
         │                  │ vk_user_id  (PK, FK)  │     │
         │                  │ candidate_id (PK, FK) │     │
         │                  └───────────────────────┘     │
         │                                                │
         └─────────────────▶┌───────────────────────┐    │
                           │   black_list          │◀────┘
                           ├───────────────────────┤
                           │ vk_user_id  (PK, FK)  │
                           │ candidate_id (PK, FK) │
                           └───────────────────────┘
```

### Описание таблиц

| Таблица | Назначение |
|---------|------------|
| **`vk_user`** | Профиль пользователя VK: возраст, пол, город, ID последнего показанного кандидата |
| **`candidates`** | Анкеты, найденные для пользователя (имя, фамилия, ссылка на VK) |
| **`photo`** | Фотографии кандидатов (attachment-строки VK API, до 3 на кандидата) |
| **`favorites`** | Избранные анкеты (связь многие-ко-многим: пользователь ↔ кандидат) |
| **`black_list`** | Чёрный список — кандидаты, которые больше не показываются |
